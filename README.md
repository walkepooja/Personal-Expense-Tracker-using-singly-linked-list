## About the Project:
This is a simple C++ project that helps user manage their daily expense using a singly linked list 

## Feature:
-Add new expense
-Display all Expense
-Track daily spending
-Simple and user-friendly program

## Technology used:
-C++
-Singly linked list
-Dynamic memory allocation

## Objective:
 The main objective of this project is to understand the practical implementation of a singly linked list in C++
